Política de privacidad

Última actualización: 24 de noviembre de 2026.

Esta aplicación es una herramienta personal que usa únicamente su propietario con su propia cuenta de TikTok. No recoge datos de otras personas.

Qué datos se usan

  • Al conectar la cuenta, TikTok entrega a la aplicación un código de autorización y tokens de acceso para el permiso video.upload (enviar vídeos al buzón de borradores).
  • Esos tokens se guardan solo en el ordenador del propietario, en un archivo local que no se sube a ningún servidor ni se comparte.
  • La aplicación no lee tu perfil, tus seguidores, tus mensajes ni tus vídeos publicados, y no usa los datos para publicidad, análisis ni venta.

Cómo retirar el permiso

El propietario puede revocar el acceso en cualquier momento desde TikTok (Ajustes y privacidad → Seguridad y permisos → Permisos de aplicaciones) o dejando de usar la herramienta.

Privacy Policy

Last updated: November 24, 2026.

This application is a personal tool used only by its owner with their own TikTok account. It does not collect data from other people.

What data is used

  • When the account is connected, TikTok gives the application an authorization code and access tokens for the video.upload permission (sending videos to the drafts inbox).
  • Those tokens are stored only on the owner's computer, in a local file that is not uploaded to any server or shared.
  • The application does not read your profile, followers, messages or published videos, and does not use data for advertising, analytics or sale.

How to revoke access

The owner can revoke access at any time from TikTok (Settings and privacy → Security & permissions → Apps and services permissions) or by ceasing to use the tool.
